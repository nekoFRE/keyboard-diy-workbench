拖动移动 · 拖圆点旋转 · 拖方块缩放 · 滚轮缩放 · 空格拖动画布

添加组件

新增组件放在空闲位置。选中后可拖动，也可输入精确坐标与尺寸。圆形组件的尺寸为直径。

外壳草案外形

默认外形参考上盖 STL 包围范围。组件坐标和尺寸是占位示意，未实测，不是加工文件。

请用导出 JSON 保存可靠副本。

快捷操作

Delete 删除选中
Ctrl D 复制选中
R 顺时针旋转 15°
方向键 移动 1 mm
Shift + 方向键 移动 5 mm
Ctrl S 导出 JSON
Esc 取消选中
