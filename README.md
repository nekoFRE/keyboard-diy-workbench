# 键盘 DIY 设计与教程工作台

通过拖拽设计键盘布局，并离线生成与当前设计关联的完整图文教程。布局仍是设计草案，实际加工参数、元件规格和电气连接需要工程验证。

## 统一使用指南

先看 [使用说明.md](使用说明.md)，所有操作说明只维护这一份正文，包含 8 张实际界面截图。也可双击 [离线图文版 HTML](使用说明图文版.html) 阅读，或打开 [图文版 PDF](使用说明图文版.pdf)。编辑器内“使用说明”使用相同内容。

## 直接使用

1. 下载整个仓库，或下载并解压 ZIP。
2. 双击 [键盘布局编辑器.html](键盘布局编辑器.html)，无需安装依赖或启动服务器。
3. 编辑布局，在“教程预览”查看联动内容，用“生成当前版本教程”保存 HTML；在浏览器打印窗口选择“另存为 PDF”。
4. 通过“项目与版本”导出完整的 `.keyboard-project.json`，保留布局版本、人工笔记、确认记录与教程背景。

需要继续分析设计时，优先提供完整项目 JSON；只提供 `.layout.json` 也可以分析布局，但不包含全部项目历史与人工内容。个人项目建议保存到 `我的项目/`，该目录默认不提交 Git。

## 能做什么

- 拖动、添加、删除、旋转与缩放按键、旋钮、转盘和 OLED，查看尺寸、间距、碰撞与基准对比。
- 根据布局 JSON 持续更新 32 章图文教程，保留未受影响的章节及人工内容；相关设计变化后提示重新复核。
- 区分物理变化与电气变化，分析 PCB、定位板、外壳、矩阵、GPIO、BOM 和 QMK 的影响。
- 保存和恢复布局版本，冻结教程版本，登记实际工程文件并导出交付 ZIP。
- 可选 AI 文件请求/响应或自有适配器；默认完整离线运行，无需 AI 服务。

## 维护开发

日常使用不需要 Node.js。维护源码使用 Node.js 20 或更新版本：

```sh
npm ci
npm run format
npm run build
npm test
npx playwright install chromium
npm run test:browser
```

`npm run format:check` 检查格式；`npm run check` 依次检查格式、构建、逻辑测试和浏览器测试。浏览器已安装后可直接运行后两项。需要使用已有 Chrome 时，通过环境变量 `CHROME_PATH` 指定可执行文件；默认使用 Playwright 的 Chromium。

修改 `_开发/` 中的源文件，再构建根目录的离线 HTML。自动生成的主 HTML、示例教程、示例项目和 Schema 随仓库提供，方便直接使用；无需手工格式化这些产物。构建会刷新项目和教程示例的版本时间，已有的原始基准和布局示例不会覆盖。

GitHub Actions 执行格式检查、构建、逻辑测试和真实浏览器回归。测试产生的截图、PDF、ZIP、临时导出文件以及升级前备份均不提交；`docs/images/` 的正式说明插图与图文指南 PDF 随仓库提供。

## 设计与资料边界

示例尺寸不等于实测尺寸，未知元件规格、电气参数与工程参数保持待确认。编辑器和教程不能直接充当可加工 PCB、外壳、定位板或可烧录固件；交付包会明确记录尚未完成的工程验证。

原视频、原教程 PDF、原始硬件附件与可执行工具不在本仓库中。现有图文资料的来源和权利说明见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。
